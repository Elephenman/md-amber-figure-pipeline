# Mn²⁺ 力场参数 — 来源与使用说明

> 2026-08-24 ｜ 决策：生产引擎 AMBER pmemd.cuda（CUDA 12），原生支持 12-6 LJ，
> 故采用 **CM 12-6（12-6 LJ 非键模型）**，不做 12-6-4（AMBER pmemd 无原生 1/r⁴ 项）。

## 1. 主用参数（本项目采用）

**CM 12-6 Mn²⁺（TIP3P）** — Li, Roberts, Chakravorty, Merz Jr.
*J. Chem. Theory Comput.* 2013, 9, 2733–2748（PMC3728907, DOI 10.1021/ct400146w）

| 量 | 值 |
|---|---|
| Rmin/2（=AMBER R\*） | **1.407 Å** |
| ε | **0.01686710 kcal/mol** |
| q | +2 |
| 质量 | 54.9380 |
| 复现 CN / IOD | 6.0 / 2.09 Å（实验 2.19 Å） |

文件：`mn_cm12-6.frcmod`（AMBER，tleap `loadamberparams` 直接加载）
     `mn_cm12-6.itp`（GROMACS 备用路径）

> "CM" = 该论文三套参数集中的 **compromise（CM）set**（针对 TIP3P 同时逼近 HFE 与结构）。
> HFE 集（R\*=1.339, ε=0.00799）与 IOD 集（R\*=1.467, ε=0.02960）同源，作为备选记录。

## 2. 备选（记录，不采用）

- **12-6-4 模型**（Li & Merz, *JCTC* 2015; PMC3960013）：Mn²⁺ TIP3P **R\*=1.485 Å, ε=0.03450196, κ=0.851 Å⁻², C4=146.1 Å⁴·kcal/mol**。
  更适合自由二价阳离子（水合/配位更准），但 AMBER pmemd 无原生 1/r⁴ 项，需 GROMACS 自定义表或补丁版 —— 与"生产用 pmemd.cuda"冲突，弃用。
- **m12-6-4 核酸平衡版**（*JCTC* 2016; PMC4762653）：针对 Mn²⁺ 与 N7(G/A) 和磷酸氧(DMP) 的位点特异结合自由能调参，最贴近"蛋白-ssDNA-Mn"场景；同为 12-6-4 形式，需 GROMACS，暂记。

## 3. 使用与验证（集群侧）

1. tleap：`loadamberparams ff/mn_cm12-6.frcmod`；把 PDB 的 `MN` HETATM 建成原子类型 MN、电荷 +2。
2. **运行前 sanity check（必须）**：短平衡后检查 Mn²⁺ 配位数 ≈ 6（H92/H96/E123 三齿 + 水/磷酸），配位数 >7 说明 12-6 过结合，需换 12-6-4 或调约束。
3. 采用 flat-bottom 约束（见 `md/` 协议）保持催化口袋几何，降低 12-6 过结合风险。

## 4. 诚实边界

- 12-6 非键模型低估二价阳离子与配体的相互作用（HFE 偏差 ~−24 kcal/mol），
  且转移性有限；在"口袋内、受约束"场景误差可控，但**不作为自由 Mn²⁺ 的定量依据**。
- ΔΔG_spec 判据本质是"同一蛋白、不同 DNA 的能量差"，Mn 的绝对建模误差在 Δ 中大量抵消。
